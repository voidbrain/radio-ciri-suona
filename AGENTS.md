# Agent Instructions

This repository is the Radio Ciri Suona app. Treat the codebase as a frontend web application and preserve the project’s existing conventions.

## Working style
- Prefer small, focused changes.
- Keep edits readable and consistent with the surrounding code.
- Do not introduce unnecessary dependencies or broad refactors.
- When uncertain, match the repository’s existing patterns rather than inventing new ones.

## Verification
- Run the relevant project checks before claiming the work is complete.
- If tests or build commands are available, verify the result with fresh evidence.

## Scope
- Make the smallest change that addresses the request.
- Center changes on user-visible behavior, maintainability, and correctness.
